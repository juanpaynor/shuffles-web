# **App Name**: Shuffles Landing

## Core Features:

- Hero Animation: Create an animated background with subtle light streaks or abstract motion, setting the cinematic tone immediately.
- Venue Showcase: Display entertainment options (Bowling, Billiards, Darts, Karaoke, Bar and Restaurant) using animated cards or panels.
- Atmosphere Visuals: Employ dark gradients and soft neon highlights to capture the nightlife atmosphere and crowd energy.
- Booking System: Enable seamless "Book Now" functionality with thumb-friendly CTAs for mobile users.
- Scroll Animations: Implement scroll-based animations such as elements that fade, slide, and scale into place, creating a natural user experience.
- Interactive Micro-interactions: Enhance engagement with subtle hover and tap micro-interactions that provide feedback and encourage exploration.

## Style Guidelines:

- Primary background color: Deep maroon (#5E1626) to evoke a premium nightlife feel.
- Primary accent and CTA color: Neon orange (#FB6241) for high-energy accents and calls to action.
- Secondary accent color: Dark maroon (#AA3A2F) for gradients and depth.
- Body and headline font: 'Space Grotesk' sans-serif with modern style, great for both headlines and body
- Employ a clean grid layout with dramatic spacing to ensure a modern, uncluttered design. The layout is primarily designed for mobile.
- Implement subtle animations and transitions to enhance user experience without being distracting or gimmicky. No parallax.
